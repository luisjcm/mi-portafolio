Solución frontend premium orientada a firmas de abogados, despachos jurídicos y consultoras legales que buscan proyectar autoridad, sobriedad y confianza en el entorno digital.

El proyecto se centró en construir una base de código altamente optimizada para producción, separando claramente la capa de presentación de los datos.

### Características Técnicas
* **Optimización para Producción:** Configuración avanzada del *bundler* (Vite) para minimizar el tamaño de los *assets* y mejorar las métricas de Core Web Vitals.
* **Componentes Reutilizables:** Creación de un sistema de diseño interno basado en Tailwind CSS, estandarizando botones, tarjetas de servicios legales, formularios de contacto y secciones de áreas de práctica.
* **Arquitectura Escalable:** Estructura de proyecto preparada para crecer e integrarse en el futuro con gestores de contenido (CMS headless) si el cliente final lo requiere.
